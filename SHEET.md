# The sheet

300 problems in one order. **Pull-based: take the next one when you sit down.**
Nothing here is scheduled to a date and nothing is ever late - a dead week costs
position, not progress. That is why the old 454-problem calendar died at 5 solved.

| tier | meaning | count |
|---|---|---|
| **A** | the spine - a bad week still does these | 101 |
| **B** | core - normal sittings | 129 |
| **C** | useful depth - only if ahead | 40 |
| **D** | **least important in its section - drop these first** | 30 |

Within a section the order is A -> B -> C -> D, easiest first, so working top-down
always does the important problems before the optional ones.

Run `python3 scripts/plan.py` rather than reading this top to bottom.
