## Workflow

1. Read the pattern guide in [`patterns/`](../patterns/) before the first problem of a new pattern
2. Attempt cold — 25 min for a Medium, 40 for a Hard
3. Timebox hit → read the editorial, close it, re-code from scratch
4. Commit with the brute force **and** optimal in the docstring (see [template](../templates/solution-template.py))
5. Paste the GitHub file link into the tracking sheet's CODE LINK column
