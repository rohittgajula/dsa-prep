# Concepts

One line per concept the daily card has explained, newest at the bottom. The
script reads this to pick a topic it has not covered yet, so the rotation never
repeats until the bank runs out.

Format: `YYYY-MM-DD — <topic, exactly as the card named it>`

The topic must match the bank entry in `scripts/daily_card.py`, or the script
will offer it again.
